\begin{remindbox}
\small A \textbf{permutation matrix} $P$ is the identity with its rows reordered; $PA$ carries out that
same row swap on $A$. When a \textbf{zero pivot} blocks $A=LU$, swap rows first --- then $PA=LU$ and you
solve $A\mathbf{x}=\mathbf{b}$ by solving $PA\mathbf{x}=P\mathbf{b}$ (swap the same entries of
$\mathbf{b}$). The swap only \textbf{reorders} the equations, so the solution $\mathbf{x}$ is unchanged.
The \textbf{transpose} $A^{\mathsf{T}}$ flips $A$ across its diagonal (rows become columns); a
\textbf{symmetric} matrix has $A^{\mathsf{T}}=A$, and $(AB)^{\mathsf{T}}=B^{\mathsf{T}}A^{\mathsf{T}}$.
\end{remindbox}
