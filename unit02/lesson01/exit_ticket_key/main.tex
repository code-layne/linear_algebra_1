\begin{enumerate}[leftmargin=1.8em, itemsep=14pt]
  \item \textbf{Solve by elimination:} $\quad 2x + y = 5,\qquad 4x + 3y = 13.$
        \begin{enumerate}[label=(\alph*), leftmargin=1.8em, itemsep=7pt]
          \item Name the \textbf{pivot} and the \textbf{multiplier} $\ell$ that clears the entry below it.
                \hfill pivot $=\ans{$2$}$\quad $\ell=\ans{$4\div2=2$}$
          \item Do the elimination step, write the upper-triangular system, and back-substitute.
                \ansline{row~2$-2\,$row~1: $(4x+3y)-2(2x+y)=13-10\Rightarrow y=3$. Triangle: $2x+y=5,\ y=3$.}
                \ansline{Back-substitute: $2x+3=5\Rightarrow x=1$.}
          \item \textbf{Check} by rebuilding $\bb$. \hfill $x=\ans{$1$}$\quad $y=\ans{$3$}$
        \end{enumerate}
        \vspace{2pt}
        {\footnotesize Check: $1\begin{bsmallmatrix} 2\\4 \end{bsmallmatrix}+3\begin{bsmallmatrix} 1\\3 \end{bsmallmatrix}=\begin{bsmallmatrix} 5\\13 \end{bsmallmatrix}$ \checkmark}
  \item \textbf{Zero pivot.} Priya starts elimination on
        $\ 0x + 3y = 9,\ \ x + 2y = 8\ $ and gets stuck: there is no pivot to work with in the top
        row. What move fixes this, \emph{why} does it work, and what is the solution?
        \ansline{\textbf{Row exchange:} swap the two equations so a nonzero $x$-coefficient sits in
        the pivot spot --- $x+2y=8,\ 3y=9$. It works because elimination needs a nonzero pivot, and
        row~2 supplies one. Then $y=3$ and $x+6=8\Rightarrow x=2$: solution $(2,3)$.}
\end{enumerate}

\begin{teachernote}
Item~1 checks the full procedure; full credit needs the pivot/multiplier named \emph{and} a check.
Item~2 is the conceptual check --- students must name the \emph{row exchange} and say \emph{why}
(no nonzero pivot without it), not just solve. Sort responses into ``procedure solid / multiplier
slip / stuck on the zero pivot'' to set up Lesson~2.2.
\end{teachernote}
