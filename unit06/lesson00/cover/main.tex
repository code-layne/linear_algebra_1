\begin{remindbox}
\small A matrix usually \emph{turns} the vectors it multiplies. But a few \textbf{special directions}
are only \emph{stretched}: a nonzero $\mathbf{x}$ with $A\mathbf{x}=\lambda\mathbf{x}$ is an
\textbf{eigenvector}, and the number $\lambda$ --- the \textbf{eigenvalue} --- is how much that
direction is scaled (and flipped, if $\lambda<0$). Along such a direction the matrix acts like a
single number. When $\lambda=0$, the direction is crushed to $\mathbf{0}$: the matrix is \emph{not
invertible} ($\det A=0$, Unit~5). These special directions run all of Unit~6.
\end{remindbox}
