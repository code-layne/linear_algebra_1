Answer rationale and Part D scoring for both Unit 1 assessments. This page is bound into the

\begin{teachernote}[Practice Test --- Part B]
Item 2: parallel columns ($\begin{bsmallmatrix}3\\6\end{bsmallmatrix}=3\begin{bsmallmatrix}1\\2\end{bsmallmatrix}$)
span only a line. Item 4: rank $1$ because column~2 is $2\times$ column~1. Watch for students
picking (A) ``rows'' in item~3 --- reinforce that $A\xx$ combines \emph{columns}.
\end{teachernote}

\begin{teachernote}[Practice Test --- Part D Scoring (5 pts each)]
Award full credit only when the student both gives the correct result and \emph{justifies} it.
D1: 2 pts (a) independence $\Rightarrow$ plane; 2 pts (b) correct weights $c=2,d=1$; 1 pt (c)
parallel $\Rightarrow$ line/rank~1. D2: 2 pts the computation $\uu\cdot\vv=0$; 3 pts interpreting
$0\Rightarrow$ perpendicular $\Rightarrow$ unrelated, with the sign meaning. Full-credit language
for the arc: \emph{combine columns $\to$ span $\to$ line vs.\ plane $\to$ reachability}.
\end{teachernote}

\begin{teachernote}[Unit Test --- Part B]
Item 2: $\begin{bsmallmatrix}4\\2\end{bsmallmatrix}=2\begin{bsmallmatrix}2\\1\end{bsmallmatrix}$
(parallel) $\Rightarrow$ line. Item 4: rank $1$ because column~2 is $2\times$ column~1. Item 6:
independent columns $\Rightarrow$ column space is all of $\mathbb R^2$.
\end{teachernote}

\begin{teachernote}[Unit Test --- Part D Scoring (5 pts each)]
Award full credit only when the student both gives the correct result and \emph{justifies} it.
D1: 2 pts (a) independence $\Rightarrow$ plane; 2 pts (b) correct weights $c=2,d=1$; 1 pt (c)
parallel $\Rightarrow$ line/rank~1. D2: 2 pts the computation $\uu\cdot\vv=0$; 3 pts interpreting
$0\Rightarrow$ perpendicular $\Rightarrow$ unrelated, with the sign meaning. This mirrors the
practice test item-for-item with new numbers.
\end{teachernote}
