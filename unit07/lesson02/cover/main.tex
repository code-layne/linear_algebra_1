\begin{remindbox}
\small The SVD writes any matrix as a sum of \textbf{rank-1 layers}, one per singular value:
$A=\sigma_1\mathbf{u}_1\mathbf{v}_1^{\top}+\sigma_2\mathbf{u}_2\mathbf{v}_2^{\top}+\cdots$, ordered from the
biggest $\sigma$ to the smallest. Each layer $\mathbf{u}\mathbf{v}^{\top}$ is a column times a row. To
\textbf{compress}, keep only the first $k$ layers: $A_k=\sigma_1\mathbf{u}_1\mathbf{v}_1^{\top}+\cdots+\sigma_k\mathbf{u}_k\mathbf{v}_k^{\top}$
--- the closest rank-$k$ matrix to $A$. Because the total ``energy'' is $\sigma_1^2+\sigma_2^2+\cdots$, the
biggest singular values carry the most of the picture, so a few layers store a near-perfect copy in a
fraction of the space.
\end{remindbox}
